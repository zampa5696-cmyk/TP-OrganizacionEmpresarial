## Qué hicimos
Analizamos un dataset de ventas simuladas usando Python. 
Calculamos cuánto se vendió en total, qué producto se vendió más
y cómo fueron las ventas mes a mes. También generamos un gráfico
para visualizar mejor los resultados.

## Dataset
Usamos un CSV con ventas de productos de tecnología (laptops, mouse, 
teclados y monitores) con fechas, cantidades y precios.
Está en la carpeta /datos.

## Cómo correr el script
1. Clonar el repo
2. Abrir Google Colab
3. Ejecutar scripts/analisis_ventas.py
4. El gráfico se guarda solo en /resultados

## Estructura del repo
- /datos → el dataset csv
- /scripts → el script de análisis
- /resultados → el gráfico generado
