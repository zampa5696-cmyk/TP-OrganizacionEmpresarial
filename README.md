## Descripción del Proyecto
Este trabajo consistió en el análisis de un conjunto de datos de ventas simuladas mediante el uso de Python. A partir de la información disponible, se realizaron distintos cálculos y métricas para obtener conclusiones relevantes sobre el desempeño de las ventas.

Entre las tareas desarrolladas se incluyen:
1. Cálculo del volumen total de ventas.
2. Identificación del producto con mayor cantidad de unidades vendidas.
3. Análisis de la evolución de las ventas a lo largo del tiempo.
4. Generación de visualizaciones gráficas para facilitar la interpretación de los resultados.

## Conjunto de Datos
Se utilizó un archivo CSV que contiene registros de ventas de productos tecnológicos, incluyendo laptops, teclados, mouse y monitores. Cada registro incorpora información sobre fecha de venta, cantidad comercializada y precio del producto.

El dataset se encuentra disponible en la carpeta /datos.

## Ejecución del Proyecto
Para ejecutar el análisis se deben seguir los siguientes pasos:
1. Clonar el repo
2. Abrir Google Colab
3. Ejecutar scripts/analisis_ventas.py
4. El gráfico generado se almacenará automáticamente en la carpeta /resultados

## Organización del Repositorio
- /datos: contiene el archivo CSV utilizado para el análisis.
- /scripts: incluye el código fuente desarrollado en Python.
- /resultados: almacena los gráficos y resultados obtenidos.
